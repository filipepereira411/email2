# C6 — Gestão do TP-Link Archer C6

Protótipo da interface HTML para gerir a rede.

## Abrir

Abra `index.html` no navegador.

> A interface é funcional como protótipo. Para controlar o router real em `192.168.0.1`, é necessário adicionar um backend local e confirmar a versão de hardware/firmware do Archer C6.
